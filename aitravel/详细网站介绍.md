# AI 智能旅行助手网站详细介绍

## 一、项目概述

### 1.1 项目背景

随着人们生活水平的提高，旅游已经成为人们休闲娱乐的重要方式之一。然而，制定一个合理的旅行计划需要花费大量的时间和精力，尤其是对于不熟悉目的地的游客来说更是如此。为了解决这一问题，我们开发了 AI 智能旅行助手网站，旨在帮助用户快速生成个性化的旅行计划，并提供地图可视化和地点管理功能。

### 1.2 项目目标

- 提供便捷的旅行计划生成功能，让用户能够快速生成详细的旅行计划
- 集成高德地图 API，实现地图可视化和地点管理功能
- 支持用户登录和注册，提供个人主页和旅行计划管理功能
- 提供探索功能，让用户能够发现热门目的地和景点

### 1.3 项目特点

- **AI 智能生成**：使用 OpenAI API 生成个性化的旅行计划
- **地图可视化**：集成高德地图 API，提供详细的地图展示和地点标记
- **响应式布局**：适配不同屏幕尺寸，小屏幕下自动调整布局
- **用户友好**：简洁直观的界面设计，易于使用
- **可扩展性**：采用模块化设计，便于后续功能扩展

## 二、技术架构

### 2.1 前端技术

- **Vue 3**：使用 Composition API 开发组件，提高代码的可维护性和可复用性
- **Vite**：快速构建和开发工具，提供热更新和快速构建功能
- **JavaScript**：主要开发语言，使用 ES6+ 语法
- **CSS**：使用 CSS 变量和响应式布局，实现样式的统一管理和适配

### 2.2 后端与 API

- **OpenAI API**：用于生成旅行计划和地点提取
- **高德地图 API**：用于地图展示和地理编码
- **Trae API**：用于生成用户头像和景点图片
- **腾讯云 CloudBase**：用于后端服务和数据存储

### 2.3 数据存储

- **LocalStorage**：存储用户信息和保存的旅行计划
- **CloudBase 数据库**：存储用户信息、旅行计划和景点数据
- **API 缓存**：缓存地理编码结果，提高响应速度

### 3.2 核心文件说明

#### 3.2.1 `TravelPlan.vue`

**功能**：旅行规划生成页面，是网站的核心功能页面

**主要组件**：
- 旅行计划生成器：用户输入旅行需求，AI 自动生成详细的每日行程
- 地图展示：使用高德地图 API 展示旅行路线和地点标记
- 地点管理：支持拖拽调整路线和地点顺序
- 保存与分享：支持保存旅行计划，登录用户可以将计划保存到个人主页

**关键技术**：
- 使用高德地图 API 实现地图可视化
- 调用 OpenAI API 生成旅行计划
- 使用 Vue 3 的 Composition API 开发组件

#### 3.2.2 `amap.service.js`

**功能**：地图服务模块，封装高德地图 API 调用

**主要功能**：
- 地理编码：将地点名称转换为经纬度
- 地点提取：从旅行计划中提取地点
- 路径规划：自动生成从起点到终点的最优路径
- 地点验证：验证地点的准确性

**关键技术**：
- 使用 fetch 调用高德地图 API
- 处理 API 响应和错误
- 实现 API 调用的缓存和重试机制

#### 3.2.3 `regenerate-plan-prompt.md`

**功能**：重新生成旅行计划的提示词文件

**主要内容**：
- 指导 AI 根据筛选后的地点重新生成旅行计划
- 要求计划详细、合理，旅行路线不能重复
- 要求一天游玩的地方不宜相距太远
- 要求计划符合用户的需求

**关键技术**：
- 使用 markdown 格式存储提示词，便于维护和更新
- 提示词工程，优化 AI 生成的结果

#### 3.2.4 `LoginModal.vue`

**功能**：登录弹窗组件，实现用户登录功能

**主要功能**：
- 用户名/密码登录
- 用户信息存储
- 登录状态管理

**关键技术**：
- 使用 Vue 3 的 Composition API 开发组件
- 表单验证和错误处理
- 与后端服务的交互

#### 3.2.5 `Profile.vue`

**功能**：个人主页组件，实现用户个人主页功能

**主要功能**：
- 用户信息展示
- 旅行计划管理
- 旅行计划复现
- 旅行计划删除

**关键技术**：
- 使用 Vue 3 的 Composition API 开发组件
- 与后端服务的交互
- 数据展示和分页

#### 3.2.6 `auth.js`

**功能**：用户认证服务，实现用户登录、注册和登出功能

**主要功能**：
- 用户注册
- 用户登录
- 用户登出
- 用户信息管理

**关键技术**：
- 与腾讯云 CloudBase 后端服务的交互
- 密码加密和安全验证

#### 3.2.7 `travelPlan.js`

**功能**：旅行计划服务，实现旅行计划的保存、查询和删除功能

## 四、核心功能详解

### 4.1 旅行规划生成

#### 4.1.1 功能流程

1. 用户在旅行规划页面输入旅行需求
2. 点击“生成计划”按钮，AI 生成详细的旅行计划
3. 系统自动提取计划中的地点，并进行地理编码
4. 根据筛选后的地点重新生成旅行计划
5. 在地图上展示旅行路线和地点标记

#### 4.1.2 技术实现

- 使用 OpenAI API 生成旅行计划
- 使用高德地图 API 进行地理编码
- 使用提示词工程优化 AI 生成的结果
- 实现地点提取和验证功能

#### 4.1.3 优化措施

- 缓存地理编码结果，提高响应速度
- 实现 API 调用的重试机制，提高系统的稳定性
- 优化提示词，提高 AI 生成结果的质量

### 4.2 地图可视化

#### 4.2.1 功能流程

1. 加载高德地图 SDK
2. 创建地图实例
3. 在地图上标记地点
4. 生成路径规划
5. 支持拖拽调整路线和地点顺序

#### 4.2.2 技术实现

- 使用高德地图 API 实现地图可视化
- 使用 AMap.DragRoute 插件实现可拖拽路线

#### 4.2.3 优化措施

- 优化地图加载速度，提高用户体验

### 4.3 用户管理

1. 用户点击登录按钮

3. 系统验证用户信息
4. 登录成功后保存用户信息到本地存储

- 使用腾讯云 CloudBase 实现用户认证

- 管理用户信息和登录状态
- 实现用户信息的本地存储

#### 4.3.3 优化措施

### 4.4 探索功能

#### 4.4.1 功能流程

1. 用户点击导航栏的“探索”按钮
2. 进入探索页面
3. 浏览热门目的地和景点信息
4. 点击景点卡片，查看景点详情和图片
