# AI 智能旅行助手网站介绍

## 项目概述

这是一个基于 Vue 3 和高德地图 API 开发的 AI 智能旅行助手网站，旨在帮助用户生成个性化的旅行计划，并提供地图可视化和地点管理功能。

## 主要功能

### 1. 旅行规划生成
- **AI 生成旅行计划**：用户输入旅行需求，AI 自动生成详细的每日行程
- **地点提取与验证**：从旅行计划中提取地点，并验证地点的准确性
- **重新生成计划**：根据筛选后的地点重新生成更合理的旅行计划
- **保存与分享**：支持保存旅行计划，登录用户可以将计划保存到个人主页

### 2. 地图可视化
- **高德地图集成**：使用高德地图 API 实现地图展示和地点标记
- **路径规划**：自动生成从起点到终点的最优路径
- **可拖拽路线**：支持拖拽调整路线和地点顺序
- **响应式布局**：适配不同屏幕尺寸，小屏幕下自动调整布局

### 3. 用户管理
- **登录/注册**：支持用户登录和注册功能
- **个人主页**：用户可以查看和管理自己保存的旅行计划
- **头像生成**：使用 AI 生成个性化用户头像

### 4. 探索功能
- **热门目的地**：展示热门旅游目的地和景点信息
- **景点详情**：查看景点的详细信息和图片
- **评论系统**：用户可以对景点进行评价和评论

## 技术栈

### 前端技术
- **Vue 3**：使用 Composition API 开发组件
- **Vite**：快速构建和开发工具
- **JavaScript**：主要开发语言
- **CSS**：使用 CSS 变量和响应式布局

### 后端与 API
- **OpenAI API**：用于生成旅行计划和地点提取
- **高德地图 API**：用于地图展示和地理编码
- **Trae API**：用于生成用户头像和景点图片

### 数据存储
- **LocalStorage**：存储用户信息和保存的旅行计划
- **API 缓存**：缓存地理编码结果，提高响应速度

## 核心文件说明

### 1. `TravelPlan.vue`
- **功能**：旅行规划生成页面，是网站的核心功能页面
- **主要组件**：包含地图展示、旅行计划生成器、地点管理等
- **关键技术**：使用高德地图 API 实现地图可视化，调用 OpenAI API 生成旅行计划

### 2. `amap.service.js`
- **功能**：地图服务模块，封装高德地图 API 调用
- **主要功能**：地理编码、地点提取、路径规划、地点验证等
- **关键技术**：使用 fetch 调用高德地图 API，处理 API 响应和错误

### 3. `regenerate-plan-prompt.md`
- **功能**：重新生成旅行计划的提示词文件
- **主要内容**：指导 AI 根据筛选后的地点重新生成旅行计划
- **关键技术**：使用 markdown 格式存储提示词，便于维护和更新

### 4. `LoginModal.vue`
- **功能**：登录弹窗组件，实现用户登录功能
- **主要功能**：用户名/密码登录，用户信息存储
- **关键技术**：使用 Vue 3 的 Composition API 开发组件

## 使用流程

### 1. 生成旅行计划
1. 用户在旅行规划页面输入旅行需求
2. 点击“生成计划”按钮，AI 生成详细的旅行计划
3. 系统自动提取计划中的地点，并进行地理编码
4. 根据筛选后的地点重新生成旅行计划
5. 在地图上展示旅行路线和地点标记

### 2. 管理旅行计划
1. 用户可以拖拽调整地图上的地点顺序
2. 点击“保存计划”按钮，将旅行计划保存到个人主页
3. 登录用户可以在个人主页查看和管理保存的计划

### 3. 探索景点
1. 点击导航栏的“探索”按钮，进入探索页面
2. 浏览热门目的地和景点信息
3. 点击景点卡片，查看景点详情和图片
4. 对景点进行评价和评论
